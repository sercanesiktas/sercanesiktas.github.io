Hakkımda

İstanbul'da yaşayan bir yazılım geliştiriciyim. Ergenlikten beri web siteleri ve uygulamalar geliştiriyorum. Geçmişimde web güvenliği de var: güvenlik açıklarını bulmak ve kapatmak.

Tek bir sorunu düzgün çözen, küçük ve testli araçları severim. Açık kaynak işlerimin çoğu gerçek projeler yaparken karşılaştığım sorunlardan çıkıyor: Türkçe metin işleme, SQLite ile MySQL arasındaki farklar, toplu işlerdeki API hataları gibi.
